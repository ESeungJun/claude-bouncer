# Claude Bouncer 기획서

관련 문서: [설계서](설계서.md) · [구현도](구현도.md) · [결정기록](결정기록.md)

## 한 줄 소개

바탕화면을 돌아다니는 작은 도트 클로드("클로디"). 같이 놀다가, Claude Code 세션이 끝나거나 나를 기다리면 커서 앞으로 달려와 어느 프로젝트·브랜치·터미널 탭에서 불렀는지 카드로 알려 준다.

## 왜 만들었나

- Claude Code를 터미널 여러 개에 띄워 두고 다른 일을 하면 "끝났나?", "권한 요청 떠 있는 거 아냐?" 하며 창을 계속 오가게 된다.
- 2026-04에 만든 v1은 화면 오른쪽 아래에서 통통 튀기만 하는 알림이었다. 그래픽이 귀엽지 않았고 버그가 많았다(개발 글).
- 그래서 2026-10에 v2로 거의 새로 만들었다. 알림만 하는 앱이 아니라 같이 노는 펫, 그리고 "누가 불렀는지"가 카드 한 장으로 끝나는 알림을 목표로 잡았다.

## 누가 쓰나

- Claude Code를 터미널·IDE 여러 곳에서 동시에 돌리는 개발자(macOS·Windows).
- claude.ai 웹 채팅을 오래 기다리는 사람(브라우저 확장).
- 개발자가 아니어도 설치 파일 하나로 쓸 수 있어야 한다(Node.js·git 불필요).

## 목표 (개발 글의 다섯 가지 기준)

1. 귀엽고, 캐주얼하게 같이 놀고 싶은 펫
2. 누가 불렀는지 카드 한 장으로 확실하게
3. 일하는 중에 방해가 되지 않게
4. 개발자가 아니어도 쉽게 설치하고 꾸밀 수 있게
5. 남의 컴퓨터 설정은 건드리지 않게

갈림길마다 이 기준으로 정했다. 자세한 결정은 [결정기록](결정기록.md)에 있다.

## 핵심 시나리오

1. **세션 완료 알림**: 터미널에서 Claude Code 작업이 끝난다 → 펫이 커서 앞으로 달려와 카드를 띄운다(종류·프로젝트·브랜치·요청·결과 요약·걸린 시간·터미널 탭) → 카드를 누르면 그 탭으로 이동한다.
2. **권한·입력 요청**: 권한 요청이 오면 카드가 처리될 때까지 남는다 → 그 세션에 다시 입력하거나, 카드를 누르거나, macOS에서 그 터미널로 직접 전환하면 카드와 알림 센터 알림이 같이 정리된다.
3. **자리 비움**: 자리를 비운 사이 알림이 쌓인다 → 돌아오면 "자리 비운 사이 알림 3개 왔어!"로 요약한다.
4. **같이 놀기**: 단축키(⌥⇧C / Alt+Shift+C)로 펫을 부른다 → 쓰다듬기·밥 주기·축구·미니게임을 한다 → 배고픔·재미·기운이 줄면 펫이 먼저 와서 조른다.
5. **나만의 캐릭터**: 패널에서 Higgsfield 계정으로 로그인 → 사진을 넣는다 → 도트 캐릭터 두 안 중 하나를 고른다. 계정이 없으면 기본 캐릭터 3종을 고르거나 제작 요청을 보낸다.
6. **claude.ai 웹**: 확장을 불러 둔다 → 웹 채팅 답변이 끝나면 카드가 뜬다(그 탭을 이미 보고 있으면 띄우지 않는다).

## 기능 목록

### 구현됨

**알림**
- 출처가 보이는 카드: 종류(작업 완료·권한 요청·입력 대기), 프로젝트, git 브랜치, 마지막 요청, 결과 요약, 걸린 시간, 터미널 앱과 탭(tty·tmux pane·Orca 패널)
- 원클릭 이동: iTerm2·macOS 터미널은 탭까지, tmux는 pane까지, Orca는 탭까지, 그 밖의 앱(VS Code·Cursor·Warp·Ghostty·JetBrains 등)은 앱을 앞으로
- 권한·입력 요청은 처리할 때까지 유지, 처리되면 자동 정리
- 작업 완료 뒤 오는 "입력을 기다려요"(idle_prompt) 알림은 완료 카드와 겹치므로 띄우지 않음
- 펫 머리 위 배지, 메뉴바 카운트, 작업 중 세션이 있으면 `•••` 말풍선
- 자리 비움 요약
- 패널: 🔔 알림함 · 🖥 세션(작업 중·응답 필요·끝남) · 🐾 펫 · ⚙ 설정
- 방해 금지(배지로만), 시스템 알림 옵션
- 집중 모드: 알림은 받고, 놀아달라고 다가오지 않음
- 돌아다니기 끄기: 알림이 와도 제자리에서 알림
- claude.ai 웹 채팅 알림(크로미움 브라우저 확장)

**펫**
- 화면 전체 투명 오버레이 위에서 돌아다니기, 펫·카드·메뉴 위에서만 클릭을 받음
- 전역 부르기 단축키(기본 Alt+Shift+C, 설정에서 변경)
- 쓰다듬기·클릭·던지기, 밥 주기(쿠키 떨어뜨리기)
- 축구하기(골대 두 개, 3골 먼저 넣으면 승리, 마우스로 공을 툭 차기)
- 미니게임: 쿠키 받기(30초), 술래잡기(20초)
- 배고픔·재미·기운, 경험치와 레벨, 낮잠
- 효과음

**나만의 캐릭터**
- Higgsfield 계정 로그인(MCP + OAuth) 또는 API 키로 연결
- 사진 → 6컷 이상 포즈 시트 → 앱이 도트 프레임으로 변환(`pixelize.js`)
- 스타일 두 가지: 도트 캐릭터(기본, 사람 모양이 아니어도 됨) / 클로디 몸에 입히기
- 만든 모습 저장(최대 8개)·바꿔 입기·삭제
- 기본 캐릭터 3종(고양이·강아지·주먹밥), 고양이·강아지는 옆모습 걷기 4컷
- 계정이 없어도 "직접 요청하기"로 사진과 메모를 개발자에게 보냄(FormSubmit)

**설치·업데이트**
- macOS dmg·zip(Apple Silicon·Intel), Windows NSIS 설치 파일
- 처음 켜면 Claude Code 훅 4개 자동 등록, 메뉴바에서 다시 설치·제거
- 앱 안 업데이트: 새 버전을 받아 SHA256SUMS와 대조한 뒤 교체·재시작
- macOS는 Developer ID 서명 + Apple 공증(v0.3.7부터)

### 나중 (근거가 있는 것만)

- Windows 코드 서명: 릴리스 워크플로에 "Windows is still unsigned" 주석이 있고 README도 SmartScreen 우회를 안내한다.

### 범위 밖

| 항목 | 이유 |
|---|---|
| Claude 데스크톱 앱 채팅 감지 | 앱이 바깥으로 알려 줄 방법이 없다(README 감지 범위 표) |
| 웹에서 실행하는 Claude Code(클라우드 세션) | 클라우드에서 돌아서 이 컴퓨터로 신호를 못 보낸다(README) |
| Firefox·Safari 확장 | 확장은 크로미움(Chrome·Edge·Brave·Arc)용 MV3만 있다 |
| Linux 설치 파일 | 훅 스크립트(`send-notify.sh`)는 Linux에서도 돌지만 빌드 대상은 macOS·Windows뿐이다 |
| 저작권 캐릭터 생성 | Higgsfield 콘텐츠 정책으로 거절된다. 앱은 거절 이유만 안내한다 |

## 지원 플랫폼과 배포 채널

- macOS(Apple Silicon·Intel), Windows 10/11
- GitHub Releases(공개 저장소 `ESeungJun/claude-bouncer`): dmg·zip·exe·SHA256SUMS만 올린다
- 소스 실행: `start.command`(macOS) / `start.bat`(Windows)
- 브라우저 확장: 스토어 배포 없이 앱이 토큰을 넣어 만든 확장 폴더를 "압축해제된 확장 프로그램"으로 불러온다

## 완료·성공 기준

- 훅 이벤트가 오면 카드에 출처(프로젝트·브랜치·터미널 탭)가 빠짐없이 뜨고, 카드를 누르면 그 탭으로 간다.
- 오버레이가 펫·카드·메뉴 밖의 클릭을 먹지 않는다.
- 훅 설치·제거가 사용자의 다른 훅과 settings.json 심볼릭 링크를 건드리지 않는다(테스트로 고정).
- `npm test`가 통과한다. 개발 글 작성 시점 기준 테스트 60개 통과(`dev-post/05-claude-bouncer/post.md`).
- 설치 파일 하나로 Node.js 없이 알림을 받는다.
- 업데이트는 체크섬이 맞을 때만 설치한다.

사용자 수·다운로드 수 같은 지표는 기록이 없어 적지 않는다.
