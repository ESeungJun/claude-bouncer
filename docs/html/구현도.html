#주요 흐름

#1. 훅 이벤트 → 카드 → 탭 이동

sequenceDiagram
  participant CC as Claude Code
  participant SH as send-notify.sh
  participant SRV as lib/server.js
  participant SES as lib/sessions.js
  participant OV as 오버레이(펫·카드)
  participant FOC as lib/focus.js
  participant T as 터미널
  CC->>SH: Stop/Notification 훅, stdin JSON
  SH->>SH: tty·tmux pane·Orca 패널 찾기
  SH->>SRV: POST /notify (토큰 헤더)
  SRV->>SRV: Host·토큰 확인
  SRV->>SES: onEvent
  SES->>SES: 대화 기록 끝 256KB에서 요청·결과 요약, git 브랜치
  SES->>OV: 카드 데이터 전달
  OV->>OV: 펫이 커서 앞으로 이동, 카드 표시
  OV->>FOC: 카드 클릭 (IPC notif:open)
  FOC->>T: AppleScript(tty) / tmux select-pane / orca CLI / 앱 활성화
  FOC-->>SES: 그 세션 카드·알림 센터 알림 정리

#2. claude.ai 웹 채팅

sequenceDiagram
  participant P as claude.ai 탭(content.js)
  participant B as background.js
  participant SRV as lib/server.js
  participant OV as 오버레이
  P->>P: data-is-streaming 속성 변화 감지
  P->>B: 시작·끝, 제목·질문·답변 앞부분
  B->>SRV: POST /notify (token.json의 토큰)
  SRV->>OV: 탭을 보고 있지 않을 때만 카드
  OV->>SRV: 카드 클릭 → 포커스 명령 큐에 넣기
  B->>SRV: GET /ext/next (롱폴)
  SRV-->>B: 탭 ID
  B->>P: 그 탭으로 전환

#빌드·실행·배포

npm install          # 처음 한 번
npm start            # 소스로 실행 (start.command / start.bat도 같은 일 + 훅 등록)
npm test             # node --test test/*.test.js
npm run install-hook # 훅 등록, --uninstall은 npm run uninstall-hook
npm run pack         # 빠른 테스트용 .app
npm run dist:mac     # dmg + zip
npm run dist:win     # NSIS 설치 파일
npm run sprites      # docs/sprite-sheet.png 다시 만들기
npm run template     # assets/skin-template.png 다시 만들기
  • 개발 중 확인은 --remote-debugging-port로 띄워 CDP로 상태 조회·캡처한다(프로젝트 메모리). 사용자 화면을 가리지 않는다.
  • 깃 흐름: master는 PR 필수. 기능 브랜치 → PR → 바로 머지(프로젝트 메모리).
  • 릴리스: master에서 package.json 버전을 올리고 master → release PR을 머지 → 워크플로가 draft 릴리스 생성 → 확인 후 공개. 이미 공개된 버전은 덮어쓰지 않는다.
  • 워크플로 수정은 커밋 전에 actionlint로 검사한다(프로젝트 메모리: SHA만 적은 액션 참조로 시작이 실패한 적이 있다).
