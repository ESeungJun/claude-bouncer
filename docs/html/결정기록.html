#2026-10-17 v1을 고치지 않고 v2로 새로 만든다

  • 무엇을 정했나: 화면 구석에서 튀기만 하던 v1을 버리고, 전체 화면 투명 오버레이 위를 돌아다니는 도트 펫으로 다시 만든다.
  • 후보: v1을 조금씩 고치기 / 새로 만들기.
  • 고른 이유: v1 그래픽이 귀엽지 않았고 버그가 많았다. 고쳐 쓰기보다 새로 만드는 게 낫다고 봤다(개발 글).
  • 누가 정했나: 사용자. "작고 귀엽게, 돌아다니며 놀고, 알림 출처는 확실하게"를 원했다(프로젝트 메모리).
  • 버린 시도: v1의 구석에서 튀는 펫, pet.html 기반 작은 창.
  • 근거: 326f0d7, 개발 글 "v1에서 뭐가 달라졌나".

#2026-10-17 카드에 출처를 전부 싣고, 권한·입력 요청은 처리될 때까지 남긴다

  • 무엇을 정했나: 카드에 종류·프로젝트·브랜치·요청·결과 요약·걸린 시간·터미널 탭을 모두 넣는다. 작업 완료는 잠깐 보이고, 권한·입력 요청은 처리될 때까지 남는다.
  • 후보: "끝났어요"만 알리기 / 출처 전체 표시.
  • 고른 이유: "끝났다"만으로는 결국 터미널을 다 열어 봐야 한다. 잠깐 떴다 사라지면 놓쳤는지도 모른다(개발 글 결정표).
  • 누가 정했나: 사용자 요구("알림 출처는 확실하게", 프로젝트 메모리).
  • 버린 시도: v1의 튀기만 하는 알림.
  • 근거: 326f0d7, 개발 글 "1. 누가 불렀는지 확실하게".

#2026-10-17 훅은 Node.js 없이 sh·PowerShell 스크립트로

  • 무엇을 정했나: 훅을 send-notify.sh·send-notify.ps1로 바꾸고, 설치형 앱은 Electron 퓨즈(RunAsNode·NODE_OPTIONS·디버거)를 끈다.

  • 버린 시도: ELECTRON_RUN_AS_NODE 방식(39ccf1c에서 도입, 몇 분 뒤 73cd4fb에서 교체). 개발 글 "5. 설치도 쉽게"는 앞의 방식으로 적혀 있다.
  • 근거: 39ccf1c → 73cd4fb. 같은 커밋에서 Electron 32(지원 종료) → 44.7.0.
